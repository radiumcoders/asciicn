## Usage

```tsx
import { AsciiShader } from "@/components/ui/ascii-shader"

export function Hero() {
  return (
    <section className="relative h-[32rem]">
      <AsciiShader seed="your-seed" field="nebula" className="absolute inset-0" />
    </section>
  )
}
```

A field pass renders the shader on the GPU at half resolution, then an ASCII pass draws one glyph per cell in the field's colour. The brighter the cell, the denser the glyph.

- **Light and dark.** Cells with nothing in them are exactly the page colour. It reads that colour from the page, or you can pass `background`.
- **Calm by default.** It pauses when it's off-screen or the tab is hidden, and holds still when reduced motion is on.
- **Monospace.** Glyphs use the `font-mono` family of your page.

The field and colour designs follow [OpenShaders](https://openshaders.com).
