## Usage

```tsx
import { AsciiSpinner } from "@/components/ui/ascii-spinner"

export function Saving() {
  return <AsciiSpinner variant="dots" label="Saving" />
}
```

The spinner reserves the width of its widest frame, so a label beside it never shifts.
