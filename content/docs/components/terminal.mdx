## Usage

A script is a list of lines. Commands are typed after the prompt; output is printed whole, after an optional `delay`.

```tsx
import { Terminal, type TerminalLine } from "@/components/ui/terminal"

const lines: TerminalLine[] = [
  { type: "command", text: "npx shadcn@latest add button" },
  { type: "output", text: "✔ Checking registry.", delay: 600 },
  { type: "output", text: "✔ Created 1 file:" },
  { type: "output", text: "  - components/ui/button.tsx" },
]

export function Example() {
  return <Terminal lines={lines} title="~/my-app" />
}
```

Output with a `delay` of 400ms or more shows a spinner while it waits. The window is `h-72` by default and scrolls to keep the newest line in view; pass a `className` to resize it.

Screen readers get the whole script at once instead of each keystroke. With reduced motion on, the finished script shows straight away.
