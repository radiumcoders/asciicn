## Usage

The field fills its parent, so give the parent a size. It draws in `currentColor`.

```tsx
import { AsciiField } from "@/components/ui/ascii-field"

export function Backdrop() {
  return (
    <div className="relative h-96 text-foreground/70">
      <AsciiField className="absolute inset-0" />
    </div>
  )
}
```

It stops drawing while it's scrolled out of view. With reduced motion on, it renders one still frame and only redraws when the pointer moves.
