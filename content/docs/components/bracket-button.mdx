## Usage

```tsx
import { BracketButton } from "@/components/ui/bracket-button"

export function Example() {
  return <BracketButton onClick={() => deploy()}>deploy</BracketButton>
}
```

A plain-text label scrambles briefly on hover and keyboard focus; other children render as they are. While `loading` is on, the label hides behind a spinner but still sets the width, so the button never jumps.
