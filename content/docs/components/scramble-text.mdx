## Usage

```tsx
import { ScrambleText } from "@/components/ui/scramble-text"

export function Example() {
  return <ScrambleText text="access granted" trigger="view" />
}
```

Changing `text` doesn't replay the effect by itself. Give the component a `key` when you want each new string to scramble in.
