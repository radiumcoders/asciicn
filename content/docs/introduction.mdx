asciicn is a set of components drawn with plain characters.

It isn't a package. Each component is a single file the [shadcn CLI](https://ui.shadcn.com/docs/cli) copies into your project. You own the code, and you can change any of it.

## Principles

- **One file per component.** No runtime dependency beyond `cn`.
- **Monochrome by default.** Everything draws in `currentColor`, so it follows your text color in light and dark mode.
- **Motion that respects people.** Every animation settles into its final state when reduced motion is on.
- **Accessible underneath.** Decorative glyphs are hidden from screen readers; the real text, role and state are always there.
