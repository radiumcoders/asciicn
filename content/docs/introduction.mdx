asciicn is a small set of components drawn with plain characters: glyphs that scramble into words, fields of text that move, loaders straight out of a terminal.

They aren't a package. Each one is a single file that the [shadcn CLI](https://ui.shadcn.com/docs/cli) copies into your project, so you own the code and can change anything.

## Principles

- **One file per component.** No runtime dependency beyond `cn`.
- **Monochrome by default.** Everything draws in `currentColor`, so components pick up your text color in light and dark mode.
- **Motion that respects people.** Every animation settles into its final state when reduced motion is on.
